# outputs/

Generated automatically when you run `main.py`. Contains:

| File | Description |
|---|---|
| `eda.png` | Class distribution + feature correlation heatmap |
| `training_curves.png` | Loss and accuracy curves |
| `evaluation.png` | Confusion matrix + ROC curve |
| `tsne.png` | t-SNE of GIN node embeddings (test set) |
| `gin_model.pt` | Best model checkpoint (excluded from Git) |
