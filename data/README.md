# data/

Place `BitcoinHeistData.csv` here before running the pipeline.

**Source:** [UCI BitcoinHeist Ransomware Address Dataset](https://archive.ics.uci.edu/dataset/526/bitcoinheist+ransomware+address+dataset)  
or download from [Kaggle](https://www.kaggle.com/datasets/mthabet/bitcoin-heist-ransomware-address-dataset).

The file is excluded from version control via `.gitignore` due to its size (~250 MB).
